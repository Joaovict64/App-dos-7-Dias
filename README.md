# App-dos-7-Dias
App Open Source
O app foi criado utilizando VibeCoding, ele é focado em pessoas que iniciam algo com grande empolgação, mas assim que encontram dificuldades param, esse app ajuda para que você faça algo em uma pequena meta de 7 dias, após está data você pode continuar com mais 7 dias, ou finalizar como um vencedor, a ferramenta foi criada utilizando o Google AI Studio, pode conter bugs, O app é focado para celulares, para maior facilidade de acesso no dia-a-dia.
